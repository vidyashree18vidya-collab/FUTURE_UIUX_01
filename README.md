# 🍔 Food Menu Delivery App - UI/UX Case Study

An intuitive, mobile-first user interface designed for a seamless food ordering experience. The project focuses on clean hierarchy, vibrant visuals, and reducing friction during the checkout process.

---

## 📱 User Flow & Screens

### 1. Welcome Splash Screen (iPhone 16)
![Splash Screen](assets/splash_screen.png) 
> **Note:* Replace assets/splash_screen.png with the actual path to your splash screen image file in your repository to fix the broken preview.*

* *Design Focus:* Captures user attention with vibrant food photography centered over an organic green gradient background.
* *UX Action:* Features an unmistakable, high-contrast primary call-to-action (*"Get Started"*) to transition users immediately into the core application experience.

---

### 2. Menu Exploration Screen (iPhone 16)
* *Layout Structure:* Organized categories using distinct visual blocks. 
* *Navigation:* Grid elements feature clear item pricing and an easily reachable bottom navigation layout for smooth, thumb-friendly transitions.

---

### 3. Product Detail Screen (iPhone 16)
* *Micro-interactions:* Features a bold price layout (₹70) and an active, intuitive item quantity adjuster.
* *UX Strategy:* Includes a horizontal *"Add Ons"* scroll area specifically designed to optimize upselling opportunities before the user hits checkout.

---

### 4. Shopping Cart & Checkout Flow (iPhone 16)
* *Friction Reduction:* Displays a clear, itemized order summary with transparent metrics totaling ₹150.
* *UX Action:* Features a dominant, full-width *"Checkout"* action block alongside custom order instruction fields to minimize cart abandonment.
