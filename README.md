🍔 Food Menu Delivery App - UI/UX Case Study

1. Welcome Splash Screen (iPhone 16 - 1)
Design Focus:* Captures user attention with vibrant food photography centered over an organic green gradient background. Features an unmistakable, high-contrast primary call-to-action ("Get Started") to transition users immediately into the core application experience.

2. Menu Exploration Screen (iPhone 16 - 2)
Layout Structure:* Organized categories using distinct visual blocks. Grid elements feature clear item pricing and an easily reachable bottom navigation layout for smooth transitions.

3. Product Detail Screen (iPhone 16 - 3)
Micro-interactions:* Features a bold price layout (₹70), an active item quantity adjuster (+/- counter), and a horizontal "Add Ons" scroll area to optimize upselling opportunities before checkout.

4. Shopping Cart & Checkout Flow (iPhone 16 - 4)
Friction Reduction:* Displays a clear order summary itemization, transparent calculation metrics totaling ₹150, and a dominant full-width "Checkout" action block alongside custom order instruction fields.


🛠️ Technical Specifications
- Design Platform:* Figma
- Target Device Frame:* iPhone 16 Layout Grid
